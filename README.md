# Social AI Club selection page

Source adapted from the TUM Social AI Club website. Cloudflare Pages serves the compiled files at the repository root from main, with no build command and output directory `.`.

## Edit and build

```sh
cd source
npm ci
npm run dev
npm run build
```

Copy the rebuilt `source/dist/index.html` and generated JavaScript, CSS, and font files into the repository root and `assets/` before committing. Copy any changed public assets to their corresponding root paths. Keep only current generated bundles.
